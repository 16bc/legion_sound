# Legion 7 16IAX7 (82TD) — фикс встроенных динамиков (CS35L41)

## Итог
Звук работает и автоматически переприменяется после каждого обновления ядра.

## Причина (кратко)
1. Модуль усилителей snd-hda-scodec-cs35l41 не знал нашу модель (CSC3551 / 17AA3874)
   -> "Platform not supported", усилители не поднимались.
2. Кодек Realtek snd-hda-codec-alc269 не имел квирка для нашего SSID 17aa:382b
   (в upstream это запись 17AA3874), поэтому кодек не подключал CS35L41 к выводу.
Оба фикса есть в upstream, но отсутствуют в установленном ядре Ubuntu.

## Что установлено
* /usr/local/sbin/cs35l41-legion-quirk            — скрипт-патчер (python3)
* /etc/kernel/postinst.d/zzz-cs35l41-legion       — хук, запускается dpkg после установки ядра
* /lib/modules/<ядро>/updates/*.ko                — патченные модули (modprobe берёт их раньше kernel/)
* /lib/firmware/cirrus/cs35l41-dsp1-spk-prot-17aa3874-* — симлинки прошивки на 17aa386f
* /root/audio-fix-backup/                         — оригиналы модулей + grub.default.bak
* /var/log/cs35l41-legion-quirk.log               — журнал патчера
* /root/audio-rollback.sh                         — полный обратимый откат

## Как это переживает обновления ядра
При установке нового ядра dpkg вызывает /etc/kernel/postinst.d/zzz-cs35l41-legion.
Скрипт:
- находит ЧИСТЫЕ модули нового ядра;
- если фикс уже есть в ядре (upstream приехал) — НИЧЕГО не делает;
- иначе патчит ПО ШАБЛОНУ, не по смещениям:
    * cs35l41: строка 17AA386F -> 17AA3874;
    * alc269 : берёт запись соседней модели Legion (17aa:386f и другие), копирует
               из неё значение фиксапа (оно МЕНЯЕТСЯ от сборки к сборке!) и подменяет
               ID на 17aa:382b;
- снимает .module_sig (после правки подпись невалидна; MODULE_SIG_FORCE выключен);
- кладёт результат в updates/, выполняет depmod и update-initramfs.
Скрипт никогда не меняет оригинальные модули и никогда не возвращает ошибку,
поэтому установка ядра не может быть сломана.

## Проверка после обновления ядра
Запусти: dmesg -T и поищи cs35l41 / alc269 / fixup.
Ждём строки: "CS35L41 Bound - SSID: 17AA3874", "bound i2c-CSC3551:00-cs35l41-hda.0",
"Firmware Loaded - Type: spk-prot", и отсутствие "Platform not supported".

Ручной запуск/переприменение:
    sudo /usr/local/sbin/cs35l41-legion-quirk 7.0.0-38-generic
Журнал:
    sudo tail -20 /var/log/cs35l41-legion-quirk.log

## Полный откат
    sudo bash /root/audio-rollback.sh
Снимает модули, симлинки И хук; файлы уносит в /root/audio-fix-disabled.

## ВАЖНО: Secure Boot
Модули неподписанные, поэтому грузятся только при ВЫКЛЮЧЕННОМ Secure Boot (сейчас так и есть).
Если включить Secure Boot в BIOS — звук пропадёт (ядро отвергнет неподписанные модули).
Решение при необходимости: подписать модули своим ключом MOK и загрузить его в прошивку.

## Если ядро Ubuntu однажды начнёт работать со звуком из коробки
Скрипт сам это обнаружит и перестанет патчить (в журнале появится "upstream fix").
Тогда всё можно снести: sudo bash /root/audio-rollback.sh
